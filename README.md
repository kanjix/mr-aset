# Сайт репетитора по математике

Личный кабинет для учеников: уроки с ссылкой на Google Meet, материалы по группам,
задания со сдачей фото и оценками. Для вас есть админка: ученики, группы, материалы,
уроки, задания, проверка работ.

Стек: Next.js (React) + Tailwind + Supabase (вход, база, файлы) + Vercel (публикация).

---

## 1. Запуск на своём компьютере

Нужен Node.js (версия LTS с nodejs.org). В Терминале, из папки проекта:

```
npm install
cp .env.local.example .env.local
```

## 2. Настройка Supabase

1. На supabase.com создайте проект (New project). Запомните пароль базы.
2. Откройте **SQL Editor -> New query**, вставьте весь файл `supabase/schema.sql` и нажмите **Run**.
3. Откройте **Project Settings -> API**. Скопируйте **Project URL** и ключ **anon public**
   (или publishable) в файл `.env.local`.
4. В разделе **Authentication** найдите настройки провайдера **Email** и выключите
   **Confirm email**. Тогда ученики входят сразу после регистрации, а вы всё равно
   подтверждаете их вручную в админке.

## 3. Первый запуск и вход администратором

```
npm run dev
```

Откройте http://localhost:3000, нажмите **Записаться** и зарегистрируйтесь своей почтой.
Затем в Supabase, в SQL Editor, выполните (подставьте свою почту):

```sql
update public.profiles
set role = 'admin', status = 'approved'
where email = 'ваша@почта.com';
```

Обновите страницу сайта: вы попадёте в админку.

Дальше в админке:
1. **Ученики**: создайте группы (например, по возрасту).
2. **Материалы**, **Уроки**, **Задания**: добавляйте для нужной группы.
3. Зарегистрируйте второй аккаунт как «ученика», подтвердите его в админке и посмотрите
   кабинет глазами ученика.

## 4. Свои тексты и контакты

Откройте `lib/config.ts` и замените имя, текст «О преподавателе», телефон, ссылки на
WhatsApp и Telegram, почту и часовой пояс. Тексты главной страницы лежат в `app/page.tsx`.

## 5. Публикация

**GitHub.** Создайте пустой репозиторий на github.com, затем в Терминале:

```
git init
git add .
git commit -m "Первая версия"
git branch -M main
git remote add origin https://github.com/ВАШ_ЛОГИН/math-tutor.git
git push -u origin main
```

**Vercel.** На vercel.com: Add New -> Project -> выберите репозиторий. В разделе
**Environment Variables** добавьте те же две переменные, что в `.env.local`
(`NEXT_PUBLIC_SUPABASE_URL` и `NEXT_PUBLIC_SUPABASE_ANON_KEY`). Нажмите **Deploy**.

**Supabase.** В Authentication -> URL Configuration укажите адрес сайта на Vercel как Site URL.

### Как обновлять сайт

Меняете файлы и отправляете изменения:

```
git add .
git commit -m "Что изменил"
git push
```

Vercel сам пересоберёт и опубликует сайт примерно за минуту.

## 6. Как поставить на телефон как приложение

- **iPhone (Safari):** Поделиться -> На экран «Домой».
- **Android (Chrome):** меню -> Установить приложение (или Добавить на главный экран).

Появится иконка, и сайт будет открываться без адресной строки. Офлайн-режима нет.

## Как это устроено

- Ученик видит только материалы, уроки и задания своей группы. Это защищено правилами
  в самой базе (Row Level Security), а не только в интерфейсе.
- Фото работ сжимаются в браузере (до 1600 px) и хранятся в файловом хранилище, в базе
  лежат только пути к ним. После проверки можно нажать «Очистить фото».
- Видеоуроки добавляются ссылкой (например, YouTube с доступом по ссылке), чтобы не
  занимать место в хранилище. Книги и презентации загружаются файлами.
- На бесплатном тарифе Supabase есть ограничения на размер файла, объём хранилища и
  неактивные проекты. Актуальные условия смотрите на supabase.com/pricing.

## Если что-то не работает

Пришлите текст ошибки из Терминала или из Vercel (вкладка Deployments -> Build Logs).
